# CS-305

  Artemis Financial is a consulting company that builds financial plans for clients, including savings, retirement, investments, and insurance. Because of the type of sensitive data they handle, their priority was securing the RESTful web application against security vulnerabilities. For this project, I completed a vulnerability assessment and identified risks in the codebase and third-party dependencies. One of the main vulnerabilities for the application was poor input validation, among insecure error handling, and outdated libraries. Addressing these issues demonstrates the importance of coding securely and using strong encryption, authentication, and clean coding practices to protect client trust and meet regulatory requirements.

  Doing this project, I learned the importance of layering security by combining manual code review with static testing tools such as the OWASP dependency check. After all changes were implemented, I tested the changes made to ensure no new vulnerabilities were added and the code still worked. The most challenging but useful part was reviewing the dependencies and CVEs, which showed just how important it is to keep libraries up to date. Future employers could see this project as proof of my ability to find and mitigate vulnerabilities, apply secure coding practices, and use industry tools to strengthen software against real-world threats.
